# Content — Button

Button copy is **2–4 words** and always leads to action. See the component itself in `reference/components/button.md`.

## Use verbs
A button is an action, so start with an **active verb** (what you're going to do) and, when needed, a **noun** that defines it — `[verb] + [noun]`. Urgency/scarcity words (`nu`, `tijdelijk`, `gratis`) also work.

- Use the **root of the verb**: "Bestel abonnement", not "Bestellen abonnement".
- **Exception — compound verbs** (*samengestelde werkwoorden*, whose root is two words): use the **full verb** instead of splitting it, so users don't have to reassemble it mentally.

## Avoid
- **Unnecessary words/articles** (*de, een, het*) — unless an article makes the line more lively per tone of voice ("Ontdek NS-app" vs "Ontdek de NS-app"; judge per case).
- **Non-guiding words** that hide what's behind the button: *Volgende, Vorige, OK, Hier, Klik hier*. Always set the expectation of what comes next. (Same rule applies to `link.md`.)

## Webshop step buttons
- Mark the next webshop step with a **yellow** button combining the root of the verb with the next page/what to expect. Tight on mobile? Refer to the page: "Naar Gegevens controleren" / "To Check your details".
- **Legal:** the **last** webshop step must read **"Bestellen en betalen"** — required by legal to signal the payment obligation. Don't reword it.

## Actions in a flow (consistency)
| Action | Copy (NL / EN) |
| :--- | :--- |
| Close the screen (e.g. after an error) | Sluit scherm / Close screen |
| Confirm a choice (e.g. in a pop-up) | Bevestig mijn keuze / Confirm my choice |

## Shared mobility verbs
Consistent verbs for shared-mobility services (bike, scooter, car):

| Situation | Dutch | English CTA |
| :--- | :--- | :--- |
| Discover the service (marketing) | Huur… | Rent… |
| Register for a service integrated in the NS app | Rijd met… [naam] | Ride with… [name] |
| Register via deeplink to the provider's app | Huur in… [naam]-app | Rent in… [name] app |
| Search in the Reisplanner | Bekijk… | View… |
| Reserve or book | Reserveer… | Reserve… |
| Upload driver's license | Voeg mijn rijbewijs toe | Add my driver's license |
| Verify license | IDnow checkt je rijbewijs | IDnow checks your driver's license |
| Open (to use) | Open het slot | Open the lock |
| Start the ride | Start mijn rit | Start my ride |
| Pause | Pauzeer mijn rit | Pause |
| Continue after pause | Verder met… | — |
| Lock | Zet op slot | Lock |
| Stop the ride/rent | Stop mijn rit | Stop my ride |
| Flow done | Dit was je rit! Sluiten | That was your ride! Close |
